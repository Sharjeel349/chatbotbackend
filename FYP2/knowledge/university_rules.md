# University advising rules

## Degree duration

The current advisor prototype uses a maximum limit of 12 registered semesters
for degree completion. When discussing a semester freeze, calculate the
remaining duration from registered semesters and advise the student to confirm
the final decision with the university administration.

## Programming workload

When a student is already taking multiple programming courses or has previously
failed a programming course, recommend a manageable workload. Explain the risk
using the student's own enrolment history instead of giving a generic warning.

## Teacher statistics

Historical grade counts are only an advising signal. Compare both failure and
high-grade counts and avoid describing a teacher as strict when the sample is
small. The final enrolment decision belongs to the student.

## Student-specific answers

For CGPA, current semester, advisor, courses, and transcript questions, use the
student database record as the source of truth. Never invent a value that is
missing from the record.
